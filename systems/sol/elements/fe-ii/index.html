Error-bar forest

How to read this forest. Each measured row is a separate abundance product for an instrument, holding, line pool and treatment; engines are never averaged together. Each bar is the uncertainty as Asplund et al. 2021 quote it: line-to-line scatter, the 3D-model term and the NLTE term (at least 0.03 dex). Atomic-data and observational terms are not in the bar, as in Asplund; they stay in the full error budget attached to the row. Green and gold regions mark the Asplund and Lodders literature values and uncertainties, not pass/fail gates. Grades describe the line pool’s provenance and selection, not the quality of an engine. Reddish-orange mean-3D / Frankenstein rows are experimental and not adopted. Unmeasured model rows remain N/A.

Grades and model labels
  • Reference Grade. An externally published reference line pool, using that reference’s line selection and oscillator strengths; the current Fe reference products use AGSS21. This is a provenance category, not a promise that every line has an individual primary-laboratory uncertainty.
  • Deep Grade. The corresponding laboratory-data pool above that depth gate. These stronger lines extend coverage but require particular care with saturation and blends.

1D-LTE uses a one-dimensional atmosphere with atomic populations in local thermodynamic equilibrium. 1D-NLTE allows departures from that equilibrium; the named implementation supplies the correction or synthesis treatment.

Mean-3D / Frankenstein combines a spatially and temporally averaged 3D atmosphere with the Gerber synthesis route. Averaging removes the full 3D fluctuations and velocity field; this experimental hybrid is not a full 3D calculation or an adopted engine.

Synthesis fits the spectral line profile. See Methodology for the full model, line-selection and uncertainty procedures.

Solar iron context

Fe II traces singly ionized iron and is retained as an ionization and consistency diagnostic alongside Fe I, not an independent headline to average with it. The current resolved pool contains strong, saturation-sensitive lines and documented blend exclusions; the diagnostics below distinguish those limitations from model and holding differences.

Near-UV opacity — report and noted

Molecular opacity INCLUDED — OH A-X, NH, CH and CN violet, 6,223 VALD lines as Turbospectrum lists with the dominant isotopologue (RYA-1207). The band previously carried none: every molecular list iSpec ships begins at 400 nm. Measured PAIRED against a molecules-off run on the same code and pool, the lever is -0.047..-0.055 dex on Fe I and -0.276..-0.332 on Fe II, with chi2r median 81.8 -> 67.4 and control windows containing no molecular line bit-identical.
