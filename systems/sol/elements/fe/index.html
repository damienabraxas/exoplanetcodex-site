Near-UV opacity — report and noted

Molecular opacity INCLUDED — OH A-X, NH, CH and CN violet, 6,223 VALD lines as Turbospectrum lists with the dominant isotopologue (RYA-1207). The band previously carried none: every molecular list iSpec ships begins at 400 nm. Measured PAIRED against a molecules-off run on the same code and pool, the lever is -0.047..-0.055 dex on Fe I and -0.276..-0.332 on Fe II, with chi2r median 81.8 -> 67.4 and control windows containing no molecular line bit-identical. RYA-1209 additionally curated out Fe I 3721.272 (systematic:K07 — gf attributed to a VALD3 reference that publishes no per-line uncertainty, no NIST accuracy class, so it never met the DEEPGRADED tier's lab-gf definition); the Fe I pool is 57 candidates and the budget clears at gf rung 3 (cited lab), 55/55 GF-LAB, RMS 0.0509 dex. RESIDUAL DEFICIT: the correction still UNDER-corrects — RYA-1204 measured synth/obs above 1 on 24 of 40 windows after it — so the band remains short of opacity by an amount not yet measured on this pool, and these values are a floor rather than a converged answer. sigma_syst is unchanged at 0.1122 because it is dominated by the 0.10 dex pseudo-continuum term, not by gf: the true continuum is never observed here. Not adopted for the headline, which rests on the VIS anchor 7.466 (RYA-161: nothing calibrated to a target).
